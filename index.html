Local-first AI for developers

Build with AI without sending your code to the cloud.

Most chat agents struggle to work clearly with Ollama and small models (4–9B parameters). OwA was built specifically for developers who run local hardware — it is designed to work well with small models like ornith:9b and qwen2.5-coder without requiring a powerful GPU or a cloud subscription.

The idea: your LLM runs on your machine, your code stays on your machine, and the agent works within your workspace — nothing leaves your hardware.

Why OwA exists

Built for local hardware, private workflows, and real coding tasks.

Local-first by design

OwA is built for developers who prefer running their own models locally instead of depending on a cloud API for every code interaction.

Small model friendly

It is designed to work well with practical local setups using moderately sized models, including common Ollama-supported chat and embedding models.

More control, less leakage

The model runs on your machine, the code stays on your machine, and the agent works inside the workspace with explicit boundaries and confirmation steps.

What it does

Workspace-aware coding assistance for everyday developer work.

Semantic code search

Index the project locally and find the most likely relevant files by context.

File reading and patching

Open files, edit targeted locations, and keep changes reviewable.

Git awareness

Inspect status, diffs, and recent commit history without leaving the repo.

Review and safety checks

Use structured checks and confirmations to reduce risky or accidental actions.

Tech stack

Small, transparent, and easy to understand.

OwA is intentionally lightweight: a Python application with a direct CLI, local intent routing, Ollama integration, local indexing, and a compact tool system that stays within the repo.
